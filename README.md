# LibDebugNew Logger

## Purpose
A library that logs data in millisecond detail, supporting performance analysis and bug tracking for Android applications.

## Scope of Use
- For debugging and application development purposes only.

- Not for cheating, hacking, or illegal purposes.

## Platform
- Android (ARM64 / x86_64)

## How to Use
1. Download `libdebugnew.zip` from the **Releases** folder.

2. Extract to get `libdebugnew.so`.

3. Embed it in your Android application.

4. Logs will be recorded in millisecond detail.
